1. Operational Latency Tiers

RAPTOR Standard

In emergency scenarios like active wildfire suppression and search & rescue (SAR), full 3D Structure-from-Motion (SfM) pipelines require 30 to 60+ minutes of dense bundle adjustment. Zenith introduces an independent 2.5D direct projection paradigm that bypasses feature matching, projecting sensor frames directly across a continuous Digital Elevation Model (DEM).

Tier Operation Latency Target Zenith Pipeline & Strategy Key Deliverables Typical Accuracy
Level 0 Emergency Thermal Triage < 2 minutes Direct ray-DEM centroid intersection without mosaic generation Ranked hotspot vector GeoJSON, instant situational JSON ±5–15 m (DEM) / ±30–50 m (Flat)
Level 1 Fast Tactical 2.5D Orthomosaic < 3 minutes Direct 2.5D parallel ray-casting with continuous DEM & Voronoi micro-feathering High-resolution Cloud-Optimized GeoTIFF (RGB/Thermal) + Float32 ENVI ±1–2 m
Level 2 Full 3D SfM (Companion) 30 – 60 minutes Asynchronous handoff to full photogrammetry (RAPTOR / ODM) Dense 3D point cloud, textured mesh, multispectral NDVI Submétrica (±0.05–0.2 m)

2. Workspace Architecture

Pure Rust Workspace

Zenith is built as a clean, highly modular Rust Cargo workspace. Responsibilities are strictly segregated between core 3D geometry, high-order geodesy, continuous DEM sampling, sensor telemetry I/O, and the Rayon-accelerated orthorectification engine.

zenith-core Geometry
Fundamental 3D vector algebra, optical heading camera models, sub-pixel ray casting, and Graham scan 2D convex hull generation.
  • Vector3, Ray3D, orthonormal camera basis
  • Brown-Conrady dynamic lens dewarp inversion
  • Graham Scan O(N log N) Convex Hull & overlap trimming
zenith-geo (projection) Geodesy
High-precision millimetric Transverse Mercator cartographic projection based on 6th-order Krüger series, matching PROJ etmerc.
  • Colombia Origen Nacional (EPSG:9377)
  • Global UTM North/South zones (EPSG:32601..32760)
  • European & American grids (EPSG:25830, EPSG:26901)
zenith-dem (topography) Surface
In-memory continuous Digital Elevation Model with bilinear cell sampling, 16-step binary bisection ray-marching, and Laplace boundary extrapolation.
  • Bilinear continuous terrain elevation interpolation
  • Sub-centimeter terrain ray-bisection intersection
  • Harmonic 2D Laplace relaxation for edge NoData cells
zenith-io (sensor) Telemetry
High-throughput DJI XMP metadata parser, geo.txt camera pose reader, and canonical v1.0 photogrammetric contract manifest serializer.
  • DJI XMP extraction: RTK positioning, gimbal angles, DewarpData
  • Laser Rangefinder (LRF) vertical datum offset calibration
  • Level 1 JSON manifest verification against RAPTOR spec
zenith-ortho Rayon SIMD
Massive multi-threaded direct 2.5D orthorectification engine. Features strict Float32 °C radiometric preservation and visual RGB micro-feathering.
  • Rayon tile-based parallel back-projection
  • Top-3 Softmin Voronoi-Band seamline micro-feathering
  • Brown-Lowe global exposure gain compensation & dehaze
zenith-cli Binary
Standalone executable CLI offering full pipeline orchestration, contract validation, synthetic benchmarks, and live progress telemetry.
  • Structured [ZENITH_PROGRESS] stdout telemetry
  • Auto-GSD derivation from sensor size & flight AGL
  • Static musl binary with zero dynamic library dependencies

3. Installation & Quickstart

Zero Dependencies

Zenith compiles to a single, self-contained static binary. Choose between downloading pre-compiled Musl binaries or building from source with Cargo.

Download the latest release binary for x86_64-unknown-linux-musl:

Bash • Release Download 
# Download the static musl binary from GitHub Releases
curl -sSL -o zenith https://github.com/federicogmz/zenith/releases/latest/download/zenith-x86_64-unknown-linux-musl
chmod +x zenith
sudo mv zenith /usr/local/bin/

# Verify binary execution
zenith --version

Compile natively with Rust 1.80+ for maximum CPU SIMD optimization:

Bash • Cargo Build 
# Clone repository
git clone https://github.com/federicogmz/zenith.git
cd zenith

# Compile release build with LTO and native codegen
cargo build --release

# The compiled binary is located at target/release/zenith
./target/release/zenith info

Quickstart Pipelines

Generate a seamless visual RGB orthomosaic with automatic GSD calculation, Voronoi micro-feathering, and global exposure gain compensation:

Bash • zenith ortho-rgb 
zenith ortho-rgb \
  --images /path/to/flight_dji_rgb/ \
  --dem /path/to/local_dtm.tif \
  --output output/rgb_orthomosaic.tif \
  --crs EPSG:9377 \
  --blend-mode micro-feather \
  --feather-px 25.0 \
  --gain-compensation \
  --trim both \
  --min-overlap 2 \
  --hull-geojson output/rgb_convex_hull.geojson \
  --manifest output/manifest_level1_rgb.json

Generate a calibrated radiometric thermal orthomosaic with strict physical °C preservation and active fire hotspot protection:

Bash • zenith ortho-thermal 
zenith ortho-thermal \
  --images /path/to/flight_dji_thermal/ \
  --raw-dir /path/to/thermal_floats_celsius/ \
  --dem /path/to/local_dtm.tif \
  --output output/thermal_orthomosaic.tif \
  --crs auto \
  --gsd 0.15 \
  --resampling nearest \
  --feather-px 6.0 \
  --max-blend-temp-diff 3.5 \
  --trim both \
  --hull-geojson output/thermal_hull.geojson \
  --manifest output/manifest_level1.json

Compute 3D camera footprints, telemetry poses, and ground footprints across the terrain elevation model:

Bash • zenith mission 
zenith mission \
  --images /path/to/flight_dji/ \
  --dem /path/to/local_dtm.tif \
  --datum-offset 0.0 \
  --max-pitch -70.0 \
  --output output/flight_footprints.geojson

Stress-test multicore direct ray-casting throughput on synthetic DEM surfaces:

Bash • zenith benchmark 
# Run 100-frame Rayon benchmark on a 1000x1000 synthetic DEM
zenith benchmark --frames 100 --dem-size 1000 --gsd 0.15

5. Algorithms & Mathematics

Scientific Rigor

Zenith pairs high-order cartographic geodesy with continuous surface ray-marching and radiometric optical models, delivering rigorous geometric accuracy without iterative bundle adjustment.

5.1 Multi-CRS Transverse Mercator Geodesy

Coordinates are projected via 6th-order Krüger series expansions on the GRS80/WGS84 ellipsoids, achieving millimetric congruence with PROJ etmerc:

Conformal Series Expansions
X = X_0 + k_0 N [ A + (1 - T + C)(A^3 / 6) + (5 - 18T + T^2 + 72C - 58e'^2)(A^5 / 120) ] Y = Y_0 + k_0 [ M + N tan φ ( A^2 / 2 + (5 - T + 9C + 4C^2)(A^4 / 24) + (61 - 58T + T^2 + 600C - 330e'^2)(A^6 / 720) ) ]

Supports Colombian Origen Nacional (EPSG:9377: Lat 4°N, Lon 73°W, $k_0 = 0.9992$, $X_0 = 5\,000\,000\text{ m}$, $Y_0 = 2\,000\,000\text{ m}$), global UTM Zones 1N–60N / 1S–60S (EPSG:32601..32760), European UTM 28N–38N (EPSG:25828..25838), and automated zone derivation (--crs auto).

5.2 Gimbal-Lock-Free Optical Heading & Brown-Conrady Dewarping

Camera orientations are computed directly in local East-North-Up (ENU) coordinates from DJI gimbal angles $(\psi_{\text{yaw}}, \theta_{\text{pitch}}, \phi_{\text{roll}})$. The forward optical vector $\vec{z}_c$ and orthogonal image axes $(\vec{x}'_c, \vec{u}'_{\text{top}})$ eliminate gimbal lock singularities:

Orthonormal Camera Basis in ENU
&vec;z_c = [ cos θ sin ψ, cos θ cos ψ, sin θ ] &vec;x_c = [ cos ψ, -sin ψ, 0 ] &vec;u_top = [ -sin θ sin ψ, -sin θ cos ψ, cos θ ] &vec;x'_c = normalize(&vec;x_c cos φ + &vec;u_top sin φ) &vec;u'_top = normalize(-&vec;x_c sin φ + &vec;u_top cos φ)

Sensor lens distortions are modeled via the Brown-Conrady formulation extracted dynamically from DJI XMP DewarpData ($f_x, f_y, c_x, c_y, k_1, k_2, p_1, p_2, k_3$). During back-projection, undistorted coordinates $(x_n, y_n)$ are reconstructed via Newton-Raphson fixed-point iteration until $\| (x_n^{(k+1)}, y_n^{(k+1)}) - (x_n^{(k)}, y_n^{(k)}) \| < 10^{-10}$.

5.3 3-Tier DEM Elevation Cascade & LRF Datum Calibration

Zenith resolves terrain elevation through an automated 3-tier cascade:

  • Tier 1 (High-Res Local): Custom GeoTIFF/ENVI DEM cropped automatically to the flight bounding box.
  • Tier 2 (Regional Satellite): Automated streaming of Copernicus GLO-30 (30m) from AWS Open Data via GDAL virtual file system (/vsicurl/).
  • Tier 3 (Contingency Plane): Automatic fallback to flight takeoff datum with Median Absolute Deviation (MAD) outlier filtering.
Laser Rangefinder (LRF) Datum Calibration
H_i = h_{\text{GNSS}, i} - N - \text{LRF}_i \cdot \cos(\alpha_{\text{nadir}, i}) N_{\text{calib}} = \text{median} \{ h_{\text{GNSS}, i} - (\text{DEM}(X_i, Y_i) + \text{LRF}_i \cdot \cos(\alpha_i)) \}

Cross-validates onboard Laser Rangefinder measurements against terrain elevations to calibrate out geoidal undulation offsets ($H = h - N$).

5.4 Visual RGB Engine: Top-3 Softmin Voronoi-Band & Dehaze

For visual RGB orthomosaics, hard Voronoi borders create conspicuous edge seams under varying illumination. Zenith implements a continuous Top-3 Softmin Voronoi-Band micro-feathering algorithm:

Top-3 Softmin Distance Weights
w_k = \frac{\exp(-d_{\text{sensor}, k} / \sigma)}{\sum_{j=1}^3 \exp(-d_{\text{sensor}, j} / \sigma)}, \quad \sigma = \text{feather\_px} I_{\text{ortho}}(X, Y) = \sum_{k=1}^3 w_k \cdot [ g_k \cdot I_k(u_k, v_k) ]

Here $g_k$ is the Brown-Lowe global exposure gain factor computed across adjacent frame overlapping regions, preventing luminance stepping across camera shots.

5.5 Radiometric Thermal Integrity & Hotspot Protection

Critical Law of Physical Radiometry

Standard photogrammetric blending averages pixel values across frames. In wildfire operations, averaging a 650°C flame pixel with a 30°C unburned background pixel dilutes the fire front to a false 340°C.

\text{If } |T_A(u, v) - T_B(u, v)| > \Delta T_{\text{max}} \ (3.5^\circ\text{C}) \implies \text{Preserve max nadir frame without blending}

Nearest-Neighbor sampling is enforced across thermal arrays. Blending is strictly restricted to narrow Voronoi borders (--feather-px 6.0) and automatically bypassed whenever temperature disparity exceeds --max-blend-temp-diff (3.5°C).
